# Портал «Перший рік анестезії»

Інтерактивний навчальний портал для інтернів-анестезіологів першого року, побудований за посібником Lachlan Rathie, *The First Year — What You Should Know After a Year of Anaesthesia* (2016).

**Живий портал:** https://paracelsus12-crypto.github.io/internship_1_year/

---

## Про проєкт

Багатосторінковий освітній портал: окрема сторінка-індекс зі змістом та вісім самостійних розділів, що відповідають структурі книги. Кожен розділ поєднує стислу теорію, таблиці, мнемоніки, чек-листи безпеки та інтерактивні тренажери.

Портал є україномовним навчальним конспектом ключових ідей посібника, а не відтворенням оригінального тексту.

## Структура розділів

| Розділ | Папка | Зміст |
|--------|-------|-------|
| Головна | `index.html` | Опис і зміст порталу |
| 1. Вступ | `intro/` | Типові помилки початківців, навчальні цілі, тренажер клінічних кейсів |
| 2. Інструменти ремесла | `tools/` | Моніторинг, наркозний апарат, інтерактивні чек-листи безпеки |
| 3. Аптечка анестезіолога | `drugs/` | Пропофол, тіопентал, кетамін, леткі агенти, міорелаксанти (таблиця доз), анальгетики |
| 4. Головна подія | `main-event/` | Оцінка, планування (PEAS), індукція, підтримка, пробудження, спінальна (CIMPLE), TCI |
| 5. Особливі пацієнти | `special-patients/` | Акушерська та педіатрична анестезія, пацієнт з ожирінням, ендоскопія |
| 6. Кнопка паніки | `crises/` | Складні дихальні шляхи, гіпоксія, гіпотензія (HPV), високий тиск у контурі |
| 7. Періоперативна медицина | `perioperative/` | Ключові дослідження, антитромботики, кровотеча й трансфузія |
| 8. Різне та корисне | `miscellany/` | ТОП-20 порад автора, вартість препаратів, підготовка до іспиту, словник |

## Інтерактивні можливості

- **Тренажер клінічних кейсів** — сценарії з вибором рішення та миттєвим зворотним звʼязком.
- **Чек-листи безпеки** — перевірка апарата та передіндукційний контроль із лічильником виконаного.
- **Пошук у словнику** — фільтрація термінів у реальному часі.
- **Адаптивна навігація** — мобільне меню, «хлібні крихти», кнопки «назад/далі» між розділами.

## Технічна архітектура

- Чистий HTML, CSS та JavaScript без збірки й зовнішніх залежностей.
- Спільні `assets/style.css` та `assets/app.js` для всіх сторінок.
- Повністю автономний — працює офлайн і на будь-якому статичному хостингу.
- Жодних зовнішніх запитів до CDN.

```
internship_1_year/
├── index.html
├── assets/
│   ├── style.css
│   └── app.js
├── intro/index.html
├── tools/index.html
├── drugs/index.html
├── main-event/index.html
├── special-patients/index.html
├── crises/index.html
├── perioperative/index.html
└── miscellany/index.html
```

## Локальний запуск

Оскільки сторінки посилаються на спільні файли в `assets/`, відкривайте портал через локальний сервер, а не подвійним кліком по файлу:

```bash
# Python 3
python3 -m http.server 8000
# потім відкрийте http://localhost:8000
```

## Розгортання (GitHub Pages)

1. Залийте вміст репозиторію у гілку `main`.
2. **Settings → Pages → Branch: `main` → `/(root)` → Save**.
3. За хвилину портал буде доступний за адресою GitHub Pages.

## Джерело та застереження

Навчальний матеріал ґрунтується на посібнику Lachlan Rathie (2016). Дозування препаратів, ціни та настанови щодо антитромботиків у першоджерелі наведено в австралійському контексті станом на 2016 рік.

> **Застереження.** Портал призначений виключно для навчальних цілей. Перед клінічним застосуванням завжди звіряйте дози, протоколи й настанови з чинними локальними інструкціями та актуальними джерелами.
